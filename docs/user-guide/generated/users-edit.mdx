View and edit an existing user.

The page is visible with the `access.system.settings.users` grant.

## Pages routes

- `/system/settings/users` — List, search and manage all users.
- `/system/settings/users/{uuid}` — View and edit an existing user. *(this page)*
- `/system/settings/users/create` — Create a new user.

## What you can do here

### How to edit a user
1. On the **Users** list page, open the row actions menu on the user you want to edit and click **Edit**.
2. Update the fields below — required: **Verified**, **Email Verified**, **Auth Method Enforcer Dismissed**, **Onboarding Completed**.
3. Click **Save** — the changes to the user are saved.

### How to grant admin rights to a user
1. In **Application Roles**, select a role whose **Admin** flag is enabled; administrator roles are marked with a **System Administrator** badge — the flag is configured on the role via **Edit Role**.
2. Click **Save** — the user now has the permissions granted by the assigned roles.


The record opens in read mode first — click **Edit** to modify it. Concurrent edits are protected by optimistic locking: if someone else saves the user while you are editing it, the page tells you before overwriting their changes. The form warns before discarding unsaved changes.

## Fields

| Field | Required | Notes |
|-------|----------|-------|
| **Display Name** | optional | text input — max 255 |
| **Email** | optional | text input — max 320 |
| **Avatar Color** | optional | shown when no avatar image is set; max 7 |
| **Avatar Initials** | optional | max 10 |
| **Verified** | required | Indicates whether the identity verification process has been successfully completed. It may depend on a KYC process or other type of verification |
| **Email Verified** | required | Indicates whether the email has been verified, typically via a link sent to the email inbox that is presumed to be readable only by the user whose profile we are configuring |
| **Application Roles** | optional | select — administrator roles show a System Administrator badge; offers the actors that wrote records of this entity; only declared values can be selected |
| **Auth Method Enforcer Dismissed** | required | checkbox |
| **Onboarding Completed** | required | — |

- The **Display Name** field is an optional text input that allows up to 255 characters.
- The **Email** field is an optional text input that allows up to 320 characters.
- The **Avatar Color** field is an optional field that allows up to 7 characters — shown when no avatar image is set.
- The **Avatar Initials** field is an optional field that allows up to 10 characters.
- The **Verified** field is a required field — indicates whether the identity verification process has been successfully completed. It may depend on a KYC process or other type of verification.
- The **Email Verified** field is a required field — indicates whether the email has been verified, typically via a link sent to the email inbox that is presumed to be readable only by the user whose profile we are configuring.
- The **Application Roles** field is an optional select — administrator roles show a System Administrator badge; offers the actors that wrote records of this entity; only declared values can be selected.
- The **Auth Method Enforcer Dismissed** field is a required checkbox.
- The **Onboarding Completed** field is a required field.

## Related entities

- A **User** is linked to **Roles** through the **Roles** field — see [Roles](/docs/user-guide/generated/roles).

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | `user_profile.update.single` | Validates the form and saves changes to the user | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and saves changes to the user and it requires the `user_profile.update.single` permission.
- The **Cancel** action is available on this page — discards changes and returns to the previous page.
