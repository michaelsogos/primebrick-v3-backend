Fill out the form to create a new organization

## Pages routes

- `/system/settings/organizations` — List, search and manage all organizations.
- `/system/settings/organizations/create` — Create a new organization. *(this page)*
- `/system/settings/organizations/{uuid}` — View and edit an existing organization.

## What you can do here

### How to create a new organization
1. On the **Organizations** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **Display name**, **Identity Name**.
3. Click **Save** — the new organization is created.

## Fields

| Field | Required | Notes |
|-------|----------|-------|
| **Display name** | required | text input |
| **Website URL** | optional | text input — max 2048; must be a valid URL |
| **Identity Owner** | optional | text input — max 255; min 1 |
| **Identity Name** | required | validated input |

- The **Display name** field is a required text input.
- The **Website URL** field is an optional text input that allows up to 2048 characters and must be a valid URL.
- The **Identity Owner** field is an optional text input that allows up to 255 characters and requires at least 1 character.
- The **Identity Name** field is a required validated input.

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | `organization.create.single` | Validates the form and creates the organization | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and creates the organization and it requires the `organization.create.single` permission.
- The **Cancel** action is available on this page — discards changes and returns to the previous page.
