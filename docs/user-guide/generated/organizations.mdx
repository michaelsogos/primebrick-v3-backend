List, search and manage all organizations.

Each row shows the Display Name, the Website URL, the User Count.

This organization is backed by the identity provider (Casdoor) — its identity fields are managed there.

## Pages routes

- `/system/settings/organizations` — List, search and manage all organizations. *(this page)*
- `/system/settings/organizations/create` — Create a new organization.
- `/system/settings/organizations/{uuid}` — View and edit an existing organization.

## What you can do here

### How to create a new organization
1. Click **New** in the toolbar.
2. Fill in the form — required: **Display name**, **Identity Name**.
3. Click **Save** — the new organization is created.

### How to edit an organization
1. Open the row actions menu on the organization and click **Edit**.
2. Update the fields — required: **Display name**, **Identity Owner**, **Identity Name**.
3. Click **Save** — the changes to the organization are saved.

### How to delete an organization
1. Open the row actions menu on the organization and click **Delete** (step-up authentication is required).
2. Confirm the deletion in the dialog — the organization is soft-deleted and can be restored.

### How to restore a deleted organization
1. Set the deleted-records filter to **Deleted only** or **All records** to show recoverable records.
2. Open the row actions menu on the organization and click **Restore**.
3. Confirm in the dialog — the organization is active again.

### How to view the change history of an organization
1. Open the row actions menu on the organization and click **Audit history**.
2. The version history of the organization will appear on the right sheet panel.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | ENABLED | `organization.create.single` | Creates a new organization | no |
| **update** | ENABLED | `organization.update.single` | Opens the organization for editing | no |
| **delete** | ENABLED | `organization.delete.single` | Marks the organization as deleted but keeps it so it can be restored | yes |
| **restore** | ENABLED | `organization.restore.single` | Brings a soft-deleted organization back | no |
| **purge** | DISABLED | — | Removes the organization forever | no |
| **audit history** | ENABLED | `organization.read.audit` | Shows the change history of the organization | no |

- Creating a new organization is available on this page — the create action opens the create form in a new browser tab and it requires the `organization.create.single` permission.
- Editing an organization is available on this page — the row action opens the record in a new browser tab and it requires the `organization.update.single` permission.
- Soft-deleting an organization is available on this page — marks the organization as deleted but keeps it so it can be restored and it requires the `organization.delete.single` permission, and step-up authentication is required.
- Restoring a soft-deleted organization is available on this page — brings a soft-deleted organization back and it requires the `organization.restore.single` permission.
- Permanently deleting an organization is not available on this page — no permission is declared for it on organizations.
- Viewing the change history of an organization is available on this page — every organization keeps a full version history and it requires the `organization.read.audit` permission.

### Bulk actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **delete** | DISABLED | `organization.delete.bulk` | Marks the selected organizations as deleted | no |
| **restore** | DISABLED | `organization.restore.bulk` | Restores the selected organizations | no |
| **duplicate** | DISABLED | `organization.duplicate.bulk` | Duplicates the selected organizations | no |
| **export** | DISABLED | `organization.export` | Exports the list | no |

- Soft-deleting the selected organizations is not available on this page — if enabled, it would require the `organization.delete.bulk` permission.
- Restoring the selected organizations is not available on this page — if enabled, it would require the `organization.restore.bulk` permission.
- Duplicating the selected organizations is not available on this page — if enabled, it would require the `organization.duplicate.bulk` permission.
- Exporting the list is not available on this page — if enabled, it would require the `organization.export` permission.
