View and edit an existing service.

The page is visible with the `access.system.settings.modules` grant.

## Pages routes

- `/system/settings/modules` — List, search and manage all services.
- `/system/settings/modules/{code}` — View and edit an existing service registry. *(this page)*

## What you can do here

### How to edit a service
1. On the **Modules** list page, open the row actions menu on the service you want to edit and click **Edit**.
2. Update the fields below — required: **active Tab**.
3. Click **Save** — the changes to the service are saved.


## Fields

| Field | Required | Notes |
|-------|----------|-------|
| **active Tab** | required | — |

- The **active Tab** field is a required field.

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | — | Validates the form and saves changes to the service | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and saves changes to the service.
- The **Cancel** action is available on this page — discards changes and returns to the previous page.
